# Synthetic dataset data dictionary

All records are synthetic and generated by
`scripts/generate_synthetic.py`. Units and permitted values are enforced by
`src/cachexia_poc/core.py`; the formal interchange schema is
`docs/schema.v1.json`.

| Field | Type / unit | Permitted values and meaning |
|---|---|---|
| `patient_id` | string | `SYN-*`; synthetic identifier only |
| `prediction_date` | ISO date | Explicit baseline and predictor cutoff |
| `age` | integer, years | 18–95 |
| `sex` | category | `female`, `male`, `unknown` |
| `cancer_type` | category | lung, colorectal, oesophageal, gastric, pancreatic, hepatobiliary, head and neck, breast, prostate, other solid tumour |
| `cancer_subtype` | string/null | SCLC or NSCLC for lung; otherwise null in v1 |
| `cancer_stage` | category | I, II, III, IV, unknown |
| `height_cm` | number/null, cm | 140–200; null means unknown |
| `weights[].date` | ISO date | Measurement date |
| `weights[].weight_kg` | number, kg | 25–160 across longitudinal records |
| `ecog` | integer/null | 0–4; null means unknown |
| `reduced_appetite` | tri-state | yes, no, unknown |
| `sarcopenia` | tri-state | yes, no, unknown; never inferred |
| `baseline_predictors` | object | Baseline-only derived variables; null means not calculable |
| `outcome_3m` | object | Independently evaluated inclusive three-calendar-month label |
| `outcome_6m` | object | Independently evaluated inclusive six-calendar-month label |
| `simulated_risk_3m` | object | Baseline-only simulation estimate, band, score, explanation |
| `simulated_risk_6m` | object | Separate baseline-only six-month simulation estimate |
| `edge_case` | string/null | Deliberately labelled reviewer example |
| `provenance` | object | Synthetic flag, seed, generator, config version, validation status |

The CSV stores longitudinal `weights` as a compact JSON string in
`weights_json`. The JSON file is canonical because it preserves nested outcome,
risk, explanation, and provenance objects without flattening.

## Workbook-sourced proposed ranges

The supplied workbook sheet `Prototype 1_agreed predictors` proposes age 18–95,
approximately balanced sex, listed solid tumour categories, greater
representation of stages III–IV, female height 140–190 cm around 162 ± 7,
male height 150–200 cm around 176 ± 7, weight 35–150 kg, BMI 15–45 kg/m²,
historical weights over the prior six months, and ECOG proportions
15%/40%/30%/12%/3% for 0/1/2/3/4 before adding a provisional unknown share.

The workbook explicitly describes these as adjustable/proposed synthetic
testing values. They are not treated as confirmed clinical requirements.
`config/simulation_assumptions.v1.json` records the operational values,
including provisional additions needed to generate a complete cohort.

## Provenance and unknowns

Unknown is never encoded as no. JSON uses `null` for unknown ECOG and
`"unknown"` for categorical tri-state fields. Derived values use `null` when
required inputs are absent. No real or identifiable health information is
included.
