Baseline-derived status uses retrospective weight evidence up to six months: >5% loss, or >2% loss with BMI <20 kg/m². For loss >2% to ≤5% with BMI ≥20, status is unknown because the sarcopenia branch is disabled pending a clinical definition. The provisional candidate rule requires cachexia criteria excluded, >1% to ≤5% loss, and baseline reduced appetite=yes. The >1% lower bound has no consensus basis and is an editable simulation parameter; ≤5% is consensus-aligned. Binary appetite is a POC simplification.
